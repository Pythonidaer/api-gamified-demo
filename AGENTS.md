# API Courier project instructions

Read WEBSITE_DESIGN_BASELINE.md and DESIGN_DECISIONS.md before UI changes. This is Pythonidaer/api-gamified-demo, branch main, published through GitHub Pages Actions. Deployable files are in dist/. typography-learning and master-icon-library are references, not deployment targets. The ChatGPT-hosted Site is a separate snapshot and does not automatically update from this repository.

Never use emojis or Unicode/text-character substitutes for UI icons. Use clear action text. The approved close SVG lives in dist/icons.js; preserve its exact saved geometry. Keep plain visible numbers, readable 16px code inputs, at least 44px touch controls, and visible focus with reserved clearance.

Preserve the user-liked courier artwork, world, and palette. Keep the page task-first and avoid oversized slogans and redundant helper copy. Mission navigation is contextual and remains in normal flow. The header uses the reference frosted sticky treatment with the game's own palette.

Preserve all missions, mock requests, error feedback, local progress/drafts, and original downloadable assets. No official Spine runtime is included without an appropriate license; do not describe the independent Canvas renderer as Spine runtime integration. Report browser verification limits honestly.
